# Contributing

Pull requests are welcome. CI runs the gate (`python -m pytest -q`); please run it
before you open one.

## Contributor Licence Agreement

Contributions to umwelt-engine are accepted under [CLA.md](CLA.md), which is currently
a draft pending review by counsel. A pull request merges only when its author has stated
this line in the pull request:

```
I have read and agree to CLA.md
```
